{{- /* ctf-mode-chips.html — the S / TT / M chip triplet for one catalog entry. Context: EITHER one challenge map from hugo.Data.huntress_ctf_2026.challenges OR a dict: entry that challenge map terse true → no visually-hidden text (the month grid is aria-hidden and names its cells itself) Status per mode (SPEC §2): release = confirmed on the release morning, later = CORRECT but not confirmed on the release morning (or the time was not recorded), open = not solved, none = the challenge does not have that mode.
